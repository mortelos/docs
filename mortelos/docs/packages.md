# Packages

MortelOS is built from Laravel packages plus a host application.

| Package | Purpose |
| --- | --- |
| `mortelos/starter` | Laravel host app template with shell, auth baseline, dashboard, inbox, governance, users, settings and diagnostics. |
| `mortelos/framework` | Framework package for MortelOS primitives such as entities, links, events, projections, tenant primitives and runtime contracts. |
| `mortelos/ui` | Shared UI primitives consumed by MortelOS packages and host apps. |

Package pages should describe stable contracts, not tenant-specific implementation details.
