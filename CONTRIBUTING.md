# Contributing

MortelOS docs are written as versioned Markdown.

## Page Rules

1. Keep public claims verifiable against a released repository or package.
2. Do not document tenant-specific routes, customer names, private policies or local UteqOS behavior.
3. Use `mortelos/framework` as the public framework package name.
4. Use `mortelos/starter` when describing the Laravel host app template.
5. Keep `slug` stable after a page is published.

## Version Rules

Version `0` lives on `main`: open pull requests against `main`. When version 1 ships, version `0` is frozen on a branch named `0` and `main` moves on to the next version.
